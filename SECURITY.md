# Security Reporting

Do not post bot tokens, server IDs, member information, private logs, or exploit details in a public issue.

Use GitHub private vulnerability reporting if it is enabled for this repository. If it is unavailable, open a minimal issue stating that you found a security concern without including secrets, private server information, or reproduction data that could affect a live server.

The public repository contains documentation only. The private bot implementation and live configuration are not distributed here.
